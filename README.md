# GRANITE: research notes prototype

A clickable prototype of a research app over an enterprise data catalog, with two concepts side by side: **A, shared note** and **B, evidence bin**.

## Run it

Needs Node 22+ and npm.

```bash
npm install
npm run dev
```

Open http://localhost:3000. Press Ctrl K (⌘K on a Mac) to search. Data is fake and lives in memory, so changes reset when the server restarts.
